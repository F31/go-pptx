## TOOL-01：CLI 与 IR（M5 收口）

### ir 只读中间表示包
- 新增 `ir/ir.go`：Document/Page/Shape/Core/Diagnostics/Box 等结构。
- SchemaVersion 常量 `"go-pptx.ir/1.0"`，与 SDK 版本独立（`SDKVersion`
  由 -ldflags 注入，默认空）。Marshal/Unmarshal 严格校验 schemaVersion，
  不匹配拒绝。
- FromPresentation 投影：core 元数据、页面顺序、SlideID/Part/Name、
  形状 ID/Kind/AltText/Decorative/Bounds/WorldBox + Chart/Table/AutoShape
  文本（GroupShape 递归子节点）；表格走 Cell.TextFrame → Paragraph.Text；
  图表走 ChartShape.Data → Type + Title + 类别；HasTiming 探测 p:timing/c:timing。
- 不嵌入媒体二进制（IR v1 不列媒体 Part；M6 媒体扫描项再补 SHA-256）。
- 5 个测试：基础投影、Chart 类型分支、Marshal-Unmarshal 往返
  （schemaVersion 拒绝/缺失拒绝/值校验）、选项默认值、nil presentation。

### CLI 二进制 cmd/pptx（§23.2）
- 6 子命令：inspect / validate / replace / narrate / timing-plan / export-ir。
- 统一退出码（§23.2）：0 OK / 1 RuntimeError / 2 UsageError / 3 Capability
  / 4 Resource（classifyError 把根包错误稳定分类：ErrInvalidArgument/
  OutOfRange→2；ErrValidationFailed/UnsupportedEdit/UnsupportedFormat/
  Closed→3；ErrLimitExceeded/OutputExists→4）。
- 写 JSON 到 stdoutW（包级变量，可被测试替换），日志到 stderrW。
- 写命令要求 --output；--overwrite 为显式覆盖。
- 只读命令（inspect/validate/timing-plan）通过 rejectOutputFlag 拒绝 --output。
- tracks.json schemaVersion 严格校验 `"go-pptx.tracks/1.0"`；重复
  trackKey/source 缺失/durationMs 非正等被拒。
- 自测试：osExit + stdoutW/stderrW 替换为 buffer，9 用例：help/version/
  未知子命令退出 2 与 stderr 提示、inspect JSON 含 IR schemaVersion、
  validate structural level 正确、export-ir --stdout 与 --output 双向
  + 重复输出需 --overwrite、replace 必填 --output、narrate schemaVersion
  拒绝 + 正常路径 appliedTo 计数、timing-plan policy="skip"、退出码常量值校验。
