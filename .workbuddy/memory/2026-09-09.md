## TEXT-03 落地（M6 第三项）

- `TextFrame.BodyProps() / SetBodyProps(BodyProps)`：R 档三字段
  `numCol/vert/anchorCtr`，`Optional[T]` 语义（仅 Set=true 字段被写/清，

  `OpenEnd-2`（`/` 之前）正确锚点。
- `Paragraph.AppendField / InsertField(at) / Fields / Remove`：`a:fld`
  白名单 `slidenum / datetime`。`FieldSpec{Kind,Guide,Text,Style}`。
  datetime `guide` 17 项白名单，未识别 ErrInvalidArgument；slidenum
  不接受 guide；未知 kind 整体 ErrUnsupportedEdit。**始终生成展开
  `a:fld…><a:t>…</a:t></a:fld>` 形态**确保 PowerPoint 识别并按
  guide 重新计算。
- `Field.Kind() / Guide() / Text() / SetText() / Remove()`：Guide 兼容
  PowerPoint 扩展属性 `fldGuide` 与旧 `guid`；SetText 在自闭合 fld 上
  自动展开为含 a:t 形态。
- **Paragraph.Text() 含字段缓存文本展示**（TEXT-03 §7.1 字段展示
  规则固定）：a:br 仍不贡献，a:fld 贡献其 a:t 缓存文本；a:r 与
  a:fld 按文档序拼接。runs/fld 互不渗透（Paragraph.Runs() 不含字段）。
- **关键设计决策**：
  - BodyProps 用 Optional 风格（不用 zero-value "删除" 语义）——
    Columns=0 / Vertical="" / AnchorCenter 未 Set 严格区分"清除"与
    "未提及"。
  - 字段句柄独立于 TextRun（共用 textNode path 基础设施），避免
    索引/迭代冲突。
  - AppendField/InsertField 始终展开 a:fld（不输出自闭合），保证
    paragraphText 能正确拼接字段位置文本（否则字段贡献空字符串）。
- **修正路径**：
  - 早期错把 BodyProps 用 int/string 字段（zero-value 歧义）→ 全部
    改为 Optional[T] 后清空语义正确。
  - 早期 SetText 走 AppendChild 在自闭合 fld 上失败 → 改为字节级
    SpanPatch 把 `/>` 替换为 `>{prefix:t}…</prefix:t></prefix:fld>`。
  - 测试初期用 `strings.Contains(err.Error(), "InvalidArgument")`
    失败（错误消息小写）→ 改为 `errors.Is(err, ErrInvalidArgument)`。
- **测试**：25 用例（BodyProps 9 例读写/patch/清除/无效/全 vert 值/
  自闭合 txBody/bodyPr 自动创建；Field 16 例：Append slidenum/datetime+
  Guide/未知 kind/非法 guide/slidenum 带 guide/Insert after Run/nil anchor/
  stale run/SetText 自闭合/转义往返/Remove/Fields 空段落/Style 透传/

  修复后 hslToRGB(120°,100%,50%) = 00FF00（此前为 000000）。
