## 测试盲区类型学（本次最大教训，4 层全漏）
1. **`map[name][]byte` 收集条目** → 同名重复互相覆盖（`rawParts` helper，`saveplan_raw_test.go:76`），**盲区根源**（未改，新测试绕开）。
2. **CI 上私有语料恒 Skip** → 真实样本守门在 CI 永不执行。
3. **末段仅 `t.Logf` 无断言** → 观察到了也没红。
4. **`Write` 单测自建 `zip.NewReader` 不校验重复** → 只验自己能读，不验条目集契约。
- **对策**：性能优化改动（尤其 ZIP/IO 层）必须跑 `SaveToFile` **端到端**校验（`Load` 接受 + 条目集比对），不能只跑 `Write` + 自建 `zip.NewReader`。计数断言须**逐条计不经 map**。
