## TPL-01 模板数据绑定引擎（M7 第四项，commit d79c5ba，已推送）
- ADR 013：绑定构建在保真补丁与跨 Run 替换之上，不引入第二套编辑路径。
- **replace.go 重构（可复用经验）**：抽出 `replacePatches(doc, para, old, rep, opts)`
  返回补丁而不做 stage/commit——TEXT-02 单段落事务与 TPL-01 按 Part 聚合两种
  粒度共用同一条保真替换路径。以后任何"多段落原子编辑"需求都走这个函数。
- **踩坑（重要）**：同段落内多个占位符各自调 replacePatches 会产生**重叠补丁**
  （ReplaceFirstCharacter 的 rebuild 覆盖整段 Run）→ 报 patch overlap。
  解法：按"起始偏移**降序**回放 + 同一段落每次替换后重新 Index +
  resolvePath 重定位"。行循环渲染同理。
- **行循环渲染**：模板行字节包一层 `<tplwrap xmlns=DrawingML xmlns:a=... >`
  （默认命名空间+前缀双声明，兼容两种源写法）→ xmlstore.Index → 逐段落
  替换/删标记 → ApplyPatches → 剥离包装。注意 a:p 在 `a:tc/a:txBody` 下，
  不是 a:tc 直接子元素（首版 bug）。
- 语法：`{{path}}` / `{{#if p}}…{{/if}}`（栈嵌套 + 全删保护保留一个空段落）/
  `{{#each p}}…{{/each}}`（表格行，标记须同行配对）/ 图表按形状名绑定 ChartData。
- 原子性：plan 纯读（缺键/类型/标记不配对/不支持构造 → 显式 error，零补丁）
  + apply 按 Part 聚合单事务 commit。图表 SetData 在文本补丁提交后执行，
  但 plan 已用 chartBindPreflight 复刻 SetData 全部前置校验。
- CLI：`pptx bind --data x.json --output out.pptx [--overwrite] [--loose]`。
  缺键错误按 classifyError 归 ExitUsageError(2) 而非 ExitCapability(3)。
- 测试：root 20 用例 + CLI 4 用例。**CLI 测试需含文本形状的文档：本库无
  AddTextbox/AddAutoShape 创建型形状 API（M2/M3 未覆盖，pptx.New()+AddSlide
