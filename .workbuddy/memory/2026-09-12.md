## 通用教训（写入 MEMORY 候选）

- **依赖审计必须在代码 commit 前做**：r0 草案列出"36 函数不反向依赖
  根包"是凭直觉，实际大量接收根包类型。按 ADR-016 "纯实现抽取"判定
  必须先 grep 出每个候选函数接收的入参类型与引用常量，再分组。
- **const 与 var 包常量的边界**：Go const 必须是编译期常量（字面量或
  常量表达式），不能跨包引用 var。根包 chartSheetName const 不能改为
  `chart.SheetName` 引用；保留 const 在根包 / 函数实现搬到 internal 是
  干净路径。
- **行为二进制兼容测试**：函数搬到新包时用真实值断言（如
  `strconv.FormatFloat(12.34, 'g', -1, 64) == "12.34"`），不能凭
  印象猜输出。`'g'/(-1)` vs `'f'/1` 差异足以破坏黄金语料哈希。
