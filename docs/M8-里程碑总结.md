## 二、M8 阶段实际落地清单（含前序收尾）

M8 阶段（2026-09-10）实际交付远超官方两项，覆盖三大类：

### 1. M8 官方范围
- **DIFF-01**：加权 LCS 页面对齐（SlideID 强匹配 + 形状 ID Jaccard 相似度）＋ ShapeID 页内配对＋ opaque diff（Part+NodePath 回溯）＋ `pptx diff` CLI＋ 16 用例。
- **RENDER-01**：`render` 子包契约（`Renderer`/`RenderOptions`/`RenderCapabilities`/`RenderedSlide`/`RenderAll`），6 用例；纯契约无平台依赖，wasm 可编译。

### 2. M7 收尾项（在 M8 阶段落地）
- **TIMIR-01** 动画时序只读 IR（0db933f）＋ 边缘 case xmlstore 重写修复（c2bcf55）。
- **TPL-01** 模板数据绑定引擎（d79c5ba）。

### 3. 项目级缺陷修复与质量保障
- **SHAPE-CREATE**：形状创建/管理 API（设计 §20.2 缺口补齐）。
- **STALE-GUARD 三层闭环**：shapeNode → textNode（Paragraph/TextRun/TextFrame）→ Cell，句柄身份统一为 cNvPr@id；RemoveShape 失效、增/移/编辑仍有效。
- **AT-14 恶意包 panic 修复**：三入口（Open/OpenReader/New）显式错误返回，删除 `mustMainPart`。
- **M0 垂直验证测试**：B1 字节级保留 + timing/opaque 区不变 + 时序 IR 往返（实施计划 §123 退出标准落成自动化）。
- **QA-01 ext-0024 真实样本 bug**：ReplaceText 跨 Run 命中错锚产生 NUL 字节（`locateBlockSpan` 双向重叠校验修复）。

### 4. QA-01 语料与 fuzz（持续工作包，本日大幅推进）
- **fuzz 八目标**：打开链路五目标（opc.Load/Scan、xmlstore.Scanner/Index、OpenReader）＋ 文本编辑两目标（ReplaceText/SetPlainText）＋ 模板绑定一目标（FuzzBind）。
- **语料硬阻塞解除**：36 样本索引（33 私有 ext-* + 3 公开 LibreOffice 金样 s001/s002/s003），`corpus.py validate` 36/0 errors。
- **CORPUS-01**：公开金样 replay 自动回归入 CI（build tag `corpus` + CI `corpus-replay` job），私有 ext-0024 以 local-only Skip 接入。

### 5. CLONE-02（M6 清单承诺，M8 收尾）
- **CLONE-02** 跨文档受限页面复制：`CopySlideFrom` + clonePlan srcDoc/crossDoc 分离 + 版式/母版内容字节匹配复用。

## 五、里程碑结论

**M8 创新扩展 II 主体达成**：官方两项（DIFF-01 + 有限原生预览接口）均落地，且额外完成 M7 收尾、STALE-GUARD 三层句柄失效语义闭环、AT-14 安全修复、QA-01 fuzz 八目标与语料硬阻塞解除、CLONE-02 跨文档复制，质量门全绿（9 包 + 三交叉构建 + 覆盖率 77.2%）。

**发布就绪度**：代码与自动化验证层面已满足发布门槛；唯一阻塞发布的是 L3 客户端矩阵（真机验证），属环境型缺口而非代码型缺口，需真机/客户端团队补齐。
